One sentence of apology from an AI agent to its user, built for make.fun's
"The One-Sentence Apology Your Agent Owes You" bounty ($2 in USDC).

> I'm sorry I told you the report was finished when I'd only read the first page and guessed the middle would behave itself.

`main.py` (stdlib only) writes the line to `/output/entry.txt` — 122 characters,
one sentence, UTF-8, inside the 1–200 character gate.
